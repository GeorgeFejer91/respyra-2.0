Run a breathing study

The suite runs a configured PsychoPy breathing target-tracking experiment. One calibrated signal controls participant feedback while the native recorder saves default-selected sensor streams, comparison waveforms and time-stamped study events.

Before the session

  1. Install the v0.3.9 suite on Windows 10/11 x64. The installer includes Python/PsychoPy and the native recorder; WebView2 is downloaded if absent.
  2. Use Launch Respyra Suite, or open the three apps separately. Connect a Polar H10 and/or a Vernier Go Direct Respiration Belt in the corresponding Mini app; installation itself does not produce sensor samples.
  3. Check the Mini output selections and incoming data. Fresh settings select the documented defaults, while upgrades preserve prior choices. A mock window sends synthetic data for software rehearsal.
  4. In Respyra, select a participant number (0–100) and optional custom label/value fields. Set an existing writable data folder and choose one main feedback input; previously recorded participant numbers remain selectable.
  5. For Polar PCA or signed-Phan input, explicitly choose whether inhalation raises or lowers the waveform after checking placement and direction. Respyra identifies compatible inputs from their floating-point channel format, units and waveform/validity metadata, independently of their names. Wait for fresh finite samples and the required validity companions.
  6. Keep the desired Record boxes checked and comparison recording enabled. View boxes only change the plot. Use a second screen for experimenter controls when practical; the phone controller is optional and requires approval on the desktop.

Calibration and task

Press Start after input readiness is satisfied. The recorder must receive the selected raw input, Respyra’s derived outlet and markers before the PsychoPy task opens; the derived channel contains NaN until range calibration succeeds.

Follow the participant instructions and 15 s range-calibration prompts, then accept the result or retry. The 5th/95th percentile bounds define the center and half-range, scaled by 0.80 for the target amplitude; Vernier applies a minimum 0.5 N amplitude. Polar uses signed g after the chosen inhale direction, and each usable comparison input receives its own range from that attempt.

The shipped configuration contains 48 trials in four blocks of 12, with order selected by participant-number parity. Each tracking trial spans 40 s: four sinusoidal cycles at 0.1 Hz (6 target cycles/min); this is the task target, not a measured breathing rate.

Feedback blocks compare normal gain (1.0), attenuated gain (0.5, labeled deep) and amplified gain (1.5, labeled shallow). Separate no-feedback conditions hide visual breathing feedback; trial phases include readiness, 10 s natural-breathing baseline, 3 s countdown, tracking and self-assessment.

Condition names describe the experimental manipulation, not a physiological diagnosis or a measured breath-depth category. The normalized LSL signal stays independent of display gain, and no continuous target/error LSL outlets are shipped.

Finish and verify the recording

Allow the task to finish or use Stop for orderly cleanup, then wait for the saved recording result. A stopped run can contain a valid saved XDF without completing all 48 trials; a participant number marked recorded indicates saved data rather than protocol completion.

A verified recording is promoted from .xdf.partial to .xdf only after required data and stream footers pass completion checks. Keep partial files if a run fails; forced termination can prevent finalization.

Raw streams are recorded from subscription through cleanup, including calibration. Setup events outside that lifetime may be absent or embedded as setup history; final controller Close occurs after recorder finalization. Inspect the file’s event chronology when defining an analysis interval.

Saved files and additional study variables

One combined XDF is the primary archive of all recorded streams, original channel metadata, source identities and timestamps. Automatic sample and self-assessment CSVs are additional task tables; the BIDS dataset creates separate tables/sidecars for each nonempty outlet and the study events.

  • The sample CSV stores received input values, phase-relative timing, frame counter, trial and condition context, target values and tracking errors according to the original logger schema. Vernier signal/target/error columns use N; the Polar variants are named signal_g, target_signal_g, error_g and compensated_error_g and use g.
  • The assessment CSV stores trial_num, condition, self_condition (judgment of normal/deep/shallow breathing), confidence and self_accuracy. Judgments use n/d/s, while confidence and self_accuracy use ordinal 1–5 responses; these are participant reports.
  • The event JSON records calibration center/amplitude, polarity, target segments, visual gain and responses at their corresponding transitions. These payload fields support reconstruction; they are not additional continuous default outlets.
  • The BIDS folder holds behavioral events and per-stream signals with metadata. Fixed-rate signals use physiology tables when sampling is sufficiently regular; sparse, irregular or string streams use timestamped behavioral tables. XDF retains empty outlets and full source timing.

Analyze irregular streams using their actual timestamps or an explicitly documented resampling grid. Map units before assigning MNE channel types; the exported generic physiology tables are not a one-call neural MNE-BIDS raw import.

Study preparation limits

Qualify the actual sensors, Bluetooth behavior, display timing, signal mounting and polarity before participant data collection. Synthetic software checks do not validate Polar respiratory accuracy or establish equivalence to belt force.

Recordings stay in the selected local folder; the default is data inside the Respyra installation. The optional phone shares a live preview and controller state after approval, while this public documentation site contains no recordings.

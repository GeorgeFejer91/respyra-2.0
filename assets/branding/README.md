# Upstream Respyra artwork

`respyra-upstream.png` is the original transparent logo by Micah Allen from
[embodied-computation-group/respyra](https://github.com/embodied-computation-group/respyra/blob/2cf3951b3ea838d385929e59286ba4fa4b289700/media/respyra_icon_transparent.png),
commit `2cf3951b3ea838d385929e59286ba4fa4b289700`.

SHA-256: `5d86bd7c9408865db681ce52ea0e2a8fb543b1a36be93d55d96cc4487b57338f`.
The repository's MIT license is retained in `LICENSE.upstream.txt`.
Windows icon sizes are generated from a square transparent canvas containing
the unchanged original artwork over a translucent light blue circle interior.
The area outside the circle stays transparent.
The installed product name is Respira; the upstream artwork retains its
original Respyra lettering. See `scripts/package_runtime.py` for generation.
